0. 記号と角度をそろえる

肩を原点 O、肘を E、目標を P = (x, y) とします。θ₁はx軸から第1リンクへの角度。θ₂は第1リンクの延長方向から第2リンクへの相対角です。第2リンクの世界座標での向きは θ₁ + θ₂ になります。

図は θ₂ が正の場合の模式図です。βも符号付きの角度として扱うので、負の分岐でも同じ式が使えます。θ₂ = 0なら伸び切った状態で、肘の三角形の内角は180°です。

1. 順運動学：2本のベクトルを足す

長さ L、向き θ のベクトルは (L cos θ, L sin θ)。肩から肘へのベクトルと、肘から手先へのベクトルを足すと、手先位置が得られます。

x = L₁ cos θ₁ + L₂ cos(θ₁ + θ₂)
y = L₁ sin θ₁ + L₂ sin(θ₁ + θ₂)

FKでは角度が入力、位置が出力。IKではこの関係を逆に解きます。ただし、位置が1つでも角度の組は1つとは限りません。

2. 余弦定理で肘の角度を求める

肩から目標までの距離を r = √(x² + y²) とすると、三角形の3辺は L₁、L₂、r です。正の分岐で肘の内角は π − θ₂。余弦定理を使うと：

r² = L₁² + L₂² − 2L₁L₂ cos(π − θ₂)
　 = L₁² + L₂² + 2L₁L₂ cos θ₂
c₂ ≔ cos θ₂ = (x² + y² − L₁² − L₂²) / (2L₁L₂)

最後が「＋」になる理由は cos(π − θ₂) = −cos θ₂ だからです。負の分岐でも cos(−θ₂) = cos θ₂ なので、最後の関係式は同じです。

別の導き方として、FKの2式を2乗して足しても、cos²θ + sin²θ = 1 と加法定理から同じ式が得られます。

θ₂ = +arccos(c₂) または −arccos(c₂)

cosは正負の角度を区別できません。この±が、目標方向を挟んだ2つの肘位置を表します。関節の周期による同値な角度を除き、到達範囲の内部では通常2解です。

3. 目標の方向から肩の角度を求める

目標の方向を α = atan2(y, x) とします。肩をまだ回していない、つまり θ₁ = 0 の座標系で考えると、手先ベクトルは次の形です。

u = L₁ + L₂ cos θ₂
v = L₂ sin θ₂
β = atan2(v, u)

このベクトルの向き β に、肩の回転 θ₁ が加わって目標方向 α になります。したがって α = θ₁ + β を並べ替えると：

θ₁ = α − β
　 = atan2(y, x)
　　 − atan2(L₂ sin θ₂, L₁ + L₂ cos θ₂)

肘の分岐を選んでから、肩を計算するのがポイント。θ₂の符号を変えるとβも変わり、同じ目標に届くようにθ₁が変わります。角度は360°の差を同じ向きとして扱います。

なぜ arctan(y / x) ではなく atan2(y, x)？

比 y/x だけでは象限が分かりません。(1, 1) と (−1, −1) は同じ比ですが、向きは180°違います。atan2はxとy両方の符号を使い、x = 0でも方向を求められます。ただし (0, 0) の方向は数学的には未定義で、別扱いが必要です。

4. 数値を入れて確かめる

初期状態の L₁ = 2、L₂ = 1.5、目標 (2.4, 1.5) を使います。以下は丸めた値です。

r² = 2.4² + 1.5² = 8.01
c₂ = (8.01 − 4 − 2.25) / 6 ≈ 0.2933
α = atan2(1.5, 2.4) ≈ 32.0°
θ₂ ≈ +72.9° → β ≈ +30.4° → θ₁ ≈ 1.6°
θ₂ ≈ −72.9° → β ≈ −30.4° → θ₁ ≈ 62.4°

どちらの角度の組もFKに戻すと、丸め誤差を除いて (2.4, 1.5) に戻ります。「リセット」後に「解の分岐」を切り替えて、上の数値と見比べてください。

5. 解が存在する範囲を式から読む

実数の角度を得るには −1 ≤ c₂ ≤ 1 が必要です。c₂の式を代入して整理すると：

(L₁ − L₂)² ≤ r² ≤ (L₁ + L₂)²
|L₁ − L₂| ≤ r ≤ L₁ + L₂

最大距離は2本を伸ばした長さの和、最小距離は折り畳んだときの長さの差。これが図の環状の到達範囲です。範囲外では元の目標に対する厳密なIK解はありません。デモは目標を境界へ射影した近似姿勢と、残る誤差を表示します。

外側の境界ではθ₂ = 0、内側ではθ₂ = ±πで、2つの分岐が同じ姿勢になります。例外として L₁ = L₂ かつ r = 0 では、θ₂ = πで折り畳むと肩角を自由に選べるため無限解です。このとき肩角の通常の式は使わず、IKモードではθ₁ = 0を代表にしています。

6. 特異点：位置の式を微分すると見える

FKを角度で微分すると、関節角の小さな変化と手先の小さな変化を結ぶ行列 J（ヤコビアン）が得られます。ここで微分に使う角度の単位はラジアンです。

δp ≈ J δθ
J₁₁ = −L₁ sin θ₁ − L₂ sin(θ₁ + θ₂)
J₁₂ = −L₂ sin(θ₁ + θ₂)
J₂₁ = L₁ cos θ₁ + L₂ cos(θ₁ + θ₂)
J₂₂ = L₂ cos(θ₁ + θ₂)
det J = J₁₁J₂₂ − J₁₂J₂₁ = L₁L₂ sin θ₂

θ₂ = 0 または ±πでは det J = 0となり、Jの逆行列が存在しません。伸び切った姿勢では、小さな関節回転が作る手先の変位はアームに垂直な方向に限られ、アーム方向の変位は一次近似では作れません。

特異点は「IK解がない」という意味ではありません。その位置には届いていても、任意の方向の微小変位を作れない状態です。近くでは、ある方向の小さな手先変位に大きな角度変化が必要になり、逆計算が敏感になります。

平面2自由度・位置のみの教材。関節制限、障害物、動力学、手先姿勢の指定は扱いません。
到達不能な場合は、目標に最も近い到達位置を表示します。IK解は移動経路の安全性を保証しません。
