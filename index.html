順運動学 / FK

角度を決めると、手先の位置が決まる。

x = L₁ cos θ₁ + L₂ cos(θ₁ + θ₂)
y = L₁ sin θ₁ + L₂ sin(θ₁ + θ₂)

逆運動学 / IK

余弦定理から肘の角度を求める。±が2つの姿勢の分岐。

c₂ = (x² + y² − L₁² − L₂²) / (2L₁L₂)
θ₂ = ± arccos(c₂)
θ₁ = atan2(y, x) − atan2(L₂ sin θ₂, L₁ + L₂ cos θ₂)

到達範囲と特異点

|L₁ − L₂| ≤ √(x² + y²) ≤ L₁ + L₂
det J = L₁L₂ sin θ₂

det J = 0ではヤコビアンの階数が落ち、瞬間的に作れる手先速度の方向が制限されます。リンクが等長で目標が原点なら、肩の角度を自由に選べる無限個の解があります。

平面2自由度・位置のみの教材。関節制限、障害物、動力学、手先姿勢の指定は扱いません。
到達不能な場合は、目標に最も近い到達位置を表示します。IK解は移動経路の安全性を保証しません。
